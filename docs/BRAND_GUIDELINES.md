# MarketBot 品牌与展示规则

更新日期：2026-10-13

产品英文名称为 **MarketBot**，中文名称为 **金融助手**。包命名空间为
`@marketbot`；资源、存储键、应用 scheme 与项目环境变量使用
`marketbot` / `MARKETBOT` 前缀。具体标识以实际配置为准，修改时同步
调用端、测试与运行工具。

网站、登录页、导航、应用元数据、代码中的产品文案以及当前方案文档使用
本项目名称。当前文档围绕金融需求、实现职责和验收证据组织，不展示早期
助手项目比较、原始营销介绍或其下载渠道。原始调研和旧方案保存在产品
目录之外的研究资料中。

品牌调整不删除适用的许可证、版权或修改说明，不改写 Git 历史，也不表示
整个代码库都是自主原创。金融引擎和其他依赖的许可说明继续按实际来源
保留。需要说明复用时，用模块职责和具体依赖事实表述，不夸大原创程度。

源码仓库为 [EthanAlgoX/MarketBot](https://github.com/EthanAlgoX/MarketBot)。
尚未配置镜像仓库、官方域名、安装包下载地址或支持邮箱。源码推送不表示
已有安装包、镜像或托管服务；其他公开入口须在实际建立后再更新。

品牌化不改变模拟模式、模型/行情门禁、原记账 Float 精度限制、真机通知
验收、用户策略适配或 72 小时运行要求。页面和宣传只能描述已经验证的
能力；规划中的研究、选股与实盘功能不能被描述为已经完整上线。
