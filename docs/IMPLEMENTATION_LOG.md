## 可信边界与接口

客户端只访问 MarketBot 严格 RPC。后端以自己的服务 token、部署 issuer 与已认证用户 subject 调用 `/internal/assistant/v1`；私有 UUID、工作区路径和 SQLite 路径不接受客户端输入。金融侧保存唯一映射，未绑定读取拒绝访问；部署管理员可明确创建自己的工作区。失去数据库不会自动重建为空账户。

| RPC / 私有接口 | 权限与含义 |
| --- | --- |
| `finance.connect` / `POST bindings/self` | 仅登录部署管理员自助创建；重复返回原绑定 |
| `finance.overview` / `GET overview` | 自选、同日账户快照、报告摘要和运行状态；金额为字符串 |
| `finance.run` / `GET runs/{id}` | 只读自己的金融库；意图/拒单/成交及业务日期分别呈现 |
| `finance.runInputs` / `GET runs/{id}/days/{recordId}/inputs` | 严格核对运行/日记录归属，读取已归档行情与来源，不刷新历史输入 |
| `finance.watchlistCommand` / `POST commands/watchlist.*` | 金融库事务保存命令与自选；稳定键和期望修订；冲突 409 |
| `finance.commandStatus` / `GET commands/{key}` | 超时先查询原命令；相同键不同内容拒绝 |
| Worker / `GET events?after=N&limit=100` | 消费已提交 Outbox；连续游标、流身份、原事件内容校验 |
| `intelligence.*` | 来源、订阅、偏好、反馈、主日报和更正；使用已认证用户身份 |
| `finance.simulationCatalog` / `simulationCommand` / `simulationCommandStatus` | 按真实目录开放规则，保存与启动分开；控制只作用自己的运行 |
| `finance.researchOverview` / `researchCommand` / `researchCommandStatus` / `researchRequest` | 耐久任务、UTC 用量、原研究/筛选结果引用和用户可见输出 |
| `finance.observations` / `saveObservation` | 只从自己的成功研究保存笔记、期限、手工失效条件与不可变原结果快照 |
| `finance.ruleDrafts` / `saveRuleDraft` / `ruleDraftStatus` | 自己的观察快照与已开放规则配置；保存、复制草稿，另行创建模拟 |
| `finance.portfolioAccounts` / `portfolioAccount` / `portfolioPreview` / `portfolioCommand` / `portfolioCommandStatus` | 仅助手创建的手工账户可写；原账本是唯一事实来源；原子回执、查重和修订校验 |

助手 PostgreSQL 保存情报档案、订阅、反馈、通知和金融事件引用。金融账本仍在 AI-Stock。Inbox、通知和游标同事务提交；重放不重复业务通知。估值日可归档，只有已提交模拟成交/拒单生成操作通知。测试事件明确标注，禁止外发。

首版 Outbox 全量追加保留，没有自动删除历史事件；一次最多读取 100 条。新推荐按原文发布时间优先、推荐时间次之，未知发布时间最后；旧日报保持原顺序。订阅预览只读已有缓存，最多扫描100条最新修订，展示匹配/排除/待复核和覆盖缺口。相同链接或同 UTC 日精确标题组成关联候选；新日报冻结分组，旧数组档案不重算，详见 [留存说明](INTELLIGENCE_RETENTION.md)。

观察保存要求成功任务与持久结果引用，幂等键和完整快照同事务写入；之后研究改变不会覆盖旧摘要。规则草稿包含观察原快照与 hash，校验规则/市场、符号、回测日期及已开放目录，保存不启动策略；失效条件目前是用户笔记，不自动判断。账户切换清空旧内存状态，迟到响应不能流入新账户。Native 六类写入口固定原身份、端点、会话世代与授权上下文，SecureStore 等待或网络等待期间退出/切换会使旧请求失效，原待确认意图保留在原账号存储中。

## 金融验证发现与处理

实际引擎发现 `floor(budget / price / lotSize)` 浮点边界可少买一个数量步长；快速暂停恢复也可能保留旧意图。已增加实际引擎回归并修复计算和暂停租约，但原 Float 持久化无法保证所有小数精确往返，不能以 DTO 字符串声称精度已解决。

新模拟已使用既有状态 JSON 中的 `decimalLedger` 作为唯一权威，旧 Float 列仅为派生兼容视图；缺权威状态不能靠 Float 重建。旧运行保留精度标记、禁止新控制；历史记账持仓全局精度仍未通过。加密价格、数量和报价金额步长为 `1e-8`，费用和舍入政策随策略冻结。耐久暂停区间立即撤销旧租约和待执行意图，恢复跳过暂停期间买卖；单 owner 停机等待实际线程完成后解锁。日资金、真实订单/成交 ID 与 Outbox 同库提交，中断重试不重复最后成交。详细证据见金融侧 `docs/assistant-finance-audit.md`。

复盘读取真实冻结策略、日输入和结果 ID，不由仓位差值推断交易。收益与回撤等属于全量样本的 `derived_float` 统计，短于 20 个交易日不显示年化/Sharpe；现金和成交仍读取精确账本字符串。

研究在原物理模型调用前预留预算、按 actual usage 结算；未知 usage 保留预留并阻断后续调用。默认每任务 20,000、UTC 每天 100,000 tokens，最多 2 个活动任务、20 次来源操作、120 秒任务期限和 2,048 输出 tokens；原 fallback 不能绕过阻断。来源限额单位是 provider operation，未声称所有第三方内部 HTTP 已有请求级严格限额。仅留用户可见输出；费用价格未知只显示用量。完整 SDK 导入验收阻断网络且不启动 lifespan；模型凭证与实际分析来源/输出还未实测，所以研究保持关闭。

手工交易写入复用原 PortfolioAccount/Trade/CashLedger，预览 hash 绑定完整原账本及修订；写入、原数据缓存失效与命令回执同事务。交易编号相同且内容一致跳过，内容变更或截至交易日卖出超持仓时阻断。原API若绕过助手修订写入不同币种现金，或不同市场/币种的交易与公司行为，明细、预览及新写入在汇总/回放前409拒绝；原已完成回执保持可查询/重放。模板上限512 KiB/1000行；不直接调用原券商CSV部分提交解析器。明细展示最多1000条，持仓计算使用完整账本；原Float精度和未验证余额显式标注。

两个金融 API 入口共享进程 owner。配置桥接时，即使研究/模拟开关关闭也会扫描已有可信绑定，恢复旧研究为 interrupted，保留预留额度，不自动重新调用模型。缺库/缺研究表不重建。停机先设研究写入栅栏，等活动金融事务和模拟线程结束再解锁；旧 SDK 返回不能再调用、结算或写入原分析/筛选记录。真实原服务写入、直接 commit、失败 rollback 和第二 owner 均有回归。
