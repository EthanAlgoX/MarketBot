## 任务执行规则

状态使用待开始、进行中、待验证、完成、阻塞或延期。同阶段按依赖执行，P1 不阻断后续 P0；依赖未满足时不启动相关写入或运行任务；只看到代码、按钮或页面不算完成。任务完成要记录改动、验证方式、证据及剩余限制。

每项任务执行记录包含负责人、开始/完成日期、产物链接、验收证据、相关 A01–A17、问题和范围变化。没有完成的测试不填写通过；外部来源或设备限制单独记录。延期 P0 或更改首期范围时同步主方案，不仅修改状态。
